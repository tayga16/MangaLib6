# MangaLib6 0.1.0

Первая опубликованная нативная сборка для ARMv7, iOS 5.1+.

- Поиск MangaLib, главы и чтение через прямой API без отдельного сервера.
- Фоновый скользящий буфер: текущая и четыре следующие страницы.
- Ограниченные повторы временных сетевых ошибок без блокировки чтения.
- Двойное нажатие: зум 2,5× и возврат к 1×; перемещение увеличенной страницы.
- Поддержка pinch до 4× через UIScrollView; жест на устройстве ещё не проверен.
- Необязательный снимок «Заботливая 800-летняя жена!», глава 1, три страницы.

## Файлы

- `MangaLib6_0.1.0.ipa` — обычная сборка, прямой API по умолчанию.
- `MangaLib6_0.1.0-smoke.ipa` — автопроверка снимка, затем живого API.
- `mangalib6-normal.png` — первая страница, буфер 5/5.
- `mangalib6-double-zoom.png` — увеличенная страница.
- `mangalib6-pan.png` — перемещение после увеличения.
- `mangalib6-next-reset.png` — следующая страница из буфера.
- `SHA256SUMS.txt` — контрольные суммы IPA и скриншотов.

Проверено в LightTouch 0.0.13, iPad/iOS 5.1.1: живой API, буфер, повторы,
двойной зум и перемещение. Физический iPad, прямой TLS и установка на него
пока не проверены. IPA требует подходящей среды установки или подписи;
это не App Store-сборка. Android-версии нет.

Для iPad 1 подходит iOS 5.1.1; обновления до iOS 6 у него нет.
