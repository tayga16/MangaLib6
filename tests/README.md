# Проверка места чтения

Тестовая сборка вызывает настоящий контроллер, заменяя сетевые запросы локальными данными.
Она использует отдельный идентификатор `ru.mangapad.progresstests`, поэтому не меняет место чтения основного приложения.

Из корня проекта:

```sh
meow -C tests build MangaLib6ProgressTests-ipa
```

Распакуй `tests/build/MangaLib6ProgressTests.ipa` и запусти приложение в HyperHLE:
Запускай из каталога эмулятора, где есть `touchHLE_fonts`, с абсолютным путём к распакованному приложению.

```sh
touchHLE unpacked/Payload/MangaLib6ProgressTests.app --no-error-popup --device-family=ipad-1 --ios-version=5.1.1 --ui-scale=1
touchHLE unpacked/Payload/MangaLib6ProgressTests.app --no-error-popup --device-family=ipad-1 --ios-version=5.1.1 --ui-scale=1 --args verify
```

Оба запуска должны завершиться с кодом 0 и сообщениями `PASS`.
Второй запуск проверяет сохранение на диске после завершения первого.
Первый проверяет возврат к дробной главе, ошибки загрузки, изменение размера главы,
позиции нескольких манг, следующую главу, направления анимаций и отключение анимации при нехватке памяти.
Также проверяет карточку продолжения: название, главу, долю прочитанных страниц и размещение над списком.
UIKit требует графический режим эмулятора; `--headless` не подходит.
Эти проверки не оценивают визуальную плавность на физическом устройстве.
