# MangaLib6

Нативная читалка MangaLib для старых iPhone и iPad: Objective-C/UIKit,
ARMv7, **iOS 5.1 и новее**. Собирается через [meow](https://github.com/sqmrak/meow).

Собрано с meow от sqmrak: https://github.com/sqmrak/meow.

Пока что только работает на iPad.

## Возможности

- Поиск манги, список глав и выбор первой доступной публичной ветки перевода.
- Дата публикации перевода главы в формате ДД.ММ.ГГГГ.
- Карточка манги с обложкой, годом, форматом, типом, количеством глав на сайте,
  статусом, авторами, издателями и альтернативными названиями (начиная с 0.2.3).
- Постраничное чтение: свайпы и кнопки перехода вперёд и назад.
- Плавный сдвиг экранов и страниц в сторону перехода; при возврате анимация идёт в обратную сторону.
- Переход к следующей главе с последней страницы кнопкой или свайпом влево.
- Автоматическое сохранение главы и страницы отдельно для каждой манги, карточка «Продолжить читать».
- В читалке: номер страницы, буфер и число загруженных страниц назад. В карточке манги — сколько страниц осталось после сохранённой в главе.
- Прямые запросы к MangaLib без отдельного сервера.
- Зум и перемещение увеличенной страницы.

Закладки, сохранение целых глав, вход в аккаунт и выбор перевода пока не реализованы.
Приложение не обходит закрытые главы, ошибки сертификатов и ограничения HTTP 403/429.
Это неофициальный экспериментальный клиент, не приложение администрации MangaLib.

## Управление

Введи название и нажми «Поиск», выбери мангу, затем «Открыть главы» и главу.
Приложение обращается к API автоматически, без кнопки переключения режима.
Карточка прокручивается; отсутствующие поля показываются как «Не указано».
Обложка загружается отдельно от информации и не задерживает загрузку глав.
«Назад» возвращает из чтения к главам, затем к карточке и результатам поиска.

Карточка «Продолжить читать» с обложкой, названием, главой, страницей и полосой прогресса
в поиске открывает последнее сохранённое место.
В карточке манги и списке глав она возвращает к сохранённой странице этой манги;
выбор отмеченной главы тоже открывает её с сохранённой страницы.
Место сохраняется после показа картинки и остаётся после закрытия приложения.
Ошибка загрузки не заменяет сохранённую позицию. Если состав главы изменился,
страница ограничивается её текущим размером; если глава исчезла, можно выбрать другую.
Сохранение позиции не загружает страницы для чтения без сети.

- Двойное нажатие на изображение увеличивает до **2,5×** вокруг выбранной точки;
  повторное возвращает **1×**.
- При масштабе **1×** свайп влево открывает следующую страницу, вправо — предыдущую.
  При увеличении свайпы перемещают изображение, не перелистывая страницу.
- Увеличенную страницу можно перемещать пальцем.
- На последней странице кнопка «Следующая глава >» и свайп влево открывают первую страницу следующей главы.
  Если следующей главы нет, кнопка «Конец манги» отключена. При ошибке загрузки можно повторить переход.
- Масштабирование двумя пальцами — до **4×**.
- При перелистывании и выходе из главы масштаб и положение сбрасываются.

## Сборка

Нужны Rust, [meow и его iOS toolchain](https://github.com/sqmrak/meow).
На Windows сборка проверена через WSL Debian. SDK 6.1 используется для сборки,
минимальная версия приложения остаётся iOS 5.1.

```sh
git clone https://github.com/tayga16/MangaLib6.git
cd MangaLib6
meow setup toolchain
meow setup sdks --sdk 6.1
meow build MangaLib6-ipa
```

Результат сборки: IPA в каталоге `build/`.

### GitHub Actions

Workflow **Build IPA** собирает приложение при push в `main`, в pull request
и вручную: **Actions → Build IPA → Run workflow**.
После успешной сборки скачай артефакт `MangaLib6-ipa` на странице запуска
и распакуй ZIP, чтобы получить IPA.

Для установки на устройство потребуется подходящая подпись или среда установки.
