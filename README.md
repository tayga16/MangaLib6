# MangaLib6

Один репозиторий с двумя нативными читалками MangaLib для старых устройств:
**MangaLib6** для iPhone и iPad на **iOS 5.1 и новее** (Objective-C/UIKit, ARMv7)
и **OldLib** для **Android 2.3 и новее** (Java, API 9).
Версия iOS собирается через [meow](https://github.com/sqmrak/meow), Android — через JDK 17 и Android SDK.

Собрано с meow от sqmrak: https://github.com/sqmrak/meow.

Один IPA подходит для iPhone и iPad. Android-версия пока тестовая;
инструкции по сборке и проверке находятся в [android/README.md](android/README.md).

## Возможности

- Поиск манги, список глав и выбор первой доступной публичной ветки перевода.
- История последних 20 поисковых запросов: повторный поиск по нажатию, удаление свайпом и очистка списка. Сохраняется после закрытия приложения.
- Дата публикации перевода главы в формате ДД.ММ.ГГГГ.
- Карточка манги с обложкой, годом, форматом, типом, количеством глав на сайте,
  статусом, авторами, издателями и альтернативными названиями (начиная с 0.2.3).
- Постраничное чтение: свайпы и кнопки перехода вперёд и назад.
- Плавный сдвиг экранов и страниц в сторону перехода; при возврате анимация идёт в обратную сторону.
- Переход к следующей главе с последней страницы кнопкой или свайпом влево.
- Автоматическое сохранение главы и страницы отдельно для каждой манги, карточка «Продолжить читать».
- Скачивание целых глав на iPhone/iPad и Android 2.3+: прогресс, отмена, продолжение и чтение без интернета через «Загрузки».
- В читалке: номер страницы, буфер и число загруженных страниц назад. В карточке манги — сколько страниц осталось после сохранённой в главе.
- Прямые запросы к MangaLib без отдельного сервера.
- Зум и перемещение увеличенной страницы.

Закладки, вход в аккаунт и выбор перевода пока не реализованы.
Приложение не обходит закрытые главы, ошибки сертификатов и ограничения HTTP 403/429.
Это неофициальный экспериментальный клиент, не приложение администрации MangaLib.

## Управление

Введи название и нажми «Поиск», выбери мангу, затем «Открыть главы» и главу.
При запуске показана история поиска; поле больше не заполнено `chainsaw`.
Кнопка «История» и нажатие на поле поиска открывают прошлые запросы, свежие сверху.
Нажатие на запрос повторяет поиск, свайп влево удаляет запись, «Очистить» удаляет всю историю.
Пустой запрос открывает историю без обращения к поисковому API.
Приложение обращается к API автоматически, без кнопки переключения режима.
Карточка прокручивается; отсутствующие поля показываются как «Не указано».
Обложка загружается отдельно от информации и не задерживает загрузку глав.
«Назад» возвращает из чтения к главам, затем к карточке и результатам поиска.

Карточка «Продолжить читать» с обложкой, названием, главой, страницей и полосой прогресса
в поиске открывает последнее сохранённое место.
В карточке манги и списке глав она возвращает к сохранённой странице этой манги;
выбор отмеченной главы тоже открывает её с сохранённой страницы.
Место сохраняется после показа картинки и остаётся после закрытия приложения.
Ошибка загрузки не заменяет сохранённую позицию. Если состав главы изменился,
страница ограничивается её текущим размером; если глава исчезла, можно выбрать другую.
Сохранение позиции не загружает страницы для чтения без сети.

Чтобы сохранить главу целиком, нажми «Скачать» рядом с ней в списке глав
(на Android — «Скачать главу»). В читалке также есть отдельная кнопка «Скачать главу».
На iPhone глава открывается на весь экран; одно касание показывает или скрывает
кнопки. Внизу остаются номер страницы, остаток и информация о буфере.
Двойное касание увеличивает страницу. «Загрузки» открывают сохранённые главы без сети,
а незавершённые позволяют продолжить скачивание с оставшихся страниц.
Скачивание идёт по одной странице; отмена, сворачивание и открытие читалки или
нового поиска приостанавливают его. Прогресс остаётся после перезапуска.
Для продолжения нужна сеть. Скачанные главы одной манги можно листать подряд;
«Продолжить читать» возвращает в сохранённую главу без обращения к API.
На iOS свайп влево удаляет загрузку, на Android есть кнопка «Удалить».
Файлы хранятся в данных приложения; удаление приложения удалит и главы.
Текущая сборка с загрузками: MangaLib6 0.5.1 (сборка 16) и OldLib 0.1.0 (сборка 16).
На iOS страницы подготавливаются в фоновом потоке в исходном разрешении.
Буфер изображений ограничен 24 МиБ на iPhone и 48 МиБ на iPad; текущая страница сохраняется.
На Android страницы загружаются с предпочтением исходного качества,
а разрешение ограничивается памятью, а не экраном. На Android 2.3.3+
при зуме видимый участок декодируется отдельно для сохранения чёткости текста.
Декодер и чёткая область переиспользуются при перемещении; разрешение участка
подбирается под масштаб, а задержка после движения сокращена до 40 мс.

- Двойное нажатие на изображение увеличивает до **2,5×** вокруг выбранной точки;
  повторное возвращает **1×**.
- При масштабе **1×** свайп влево открывает следующую страницу, вправо — предыдущую.
  При увеличении свайпы перемещают изображение, не перелистывая страницу.
- Увеличенную страницу можно перемещать пальцем.
- На последней странице кнопка «Следующая глава >» и свайп влево открывают первую страницу следующей главы.
  Если следующей главы нет, кнопка «Конец манги» отключена. При ошибке загрузки можно повторить переход.
- Масштабирование двумя пальцами — до **4×**.
- При перелистывании и выходе из главы масштаб и положение сбрасываются.

## Сборка

Нужны Rust, [meow и его iOS toolchain](https://github.com/sqmrak/meow).
На Windows сборка проверена через meow 2.0stable и Clang. SDK 6.1 используется для сборки,
минимальная версия приложения остаётся iOS 5.1.

```sh
git clone https://github.com/tayga16/MangaLib6.git
cd MangaLib6
meow setup toolchain
meow setup sdks --sdk 6.1
meow build MangaLib6-ipa
```

Результат сборки: IPA в каталоге `build/`.

### Cydia-репозиторий

Для устройств с jailbreak доступны DEB и архив статического репозитория в релизе 0.5.1.
Сборка пакета и подготовка каталога для `http://tayga16.ru/repo/`:

```sh
meow build MangaLib6-deb
python tools/cydia_repo.py --deb build/ru.mangapad.apitest_0.5.1_iphoneos-arm.deb --ipa build/MangaLib6_0.5.1.ipa
```

Файлы появятся в `build/cydia/repo/`. Размещение на Linux-сервере описано
в [packaging/README.md](packaging/README.md). Адрес источника станет доступен после размещения файлов на сервере.

### GitHub Actions

Workflow **Build IPA** собирает приложение при push в `main`, в pull request
и вручную: **Actions → Build IPA → Run workflow**. Он также собирает DEB,
проверяет пакеты и формирует архив Cydia-репозитория.
После успешной сборки скачай артефакт `MangaLib6-ipa` на странице запуска
и распакуй ZIP, чтобы получить IPA.
Артефакт `MangaLib6-cydia` содержит DEB и архив для размещения на сервере.

Для установки на устройство потребуется подходящая подпись или среда установки.
