# MangaLib6

Нативная читалка MangaLib для старых iPhone и iPad: Objective-C/UIKit,
ARMv7, **iOS 5.1 и новее**. Собирается через [meow](https://github.com/sqmrak/meow).

Пока что только работает на iPad.

## Возможности

- Поиск манги, список глав и выбор первой доступной публичной ветки перевода.
- Карточка манги с обложкой, годом, форматом, типом, количеством глав на сайте,
  статусом, авторами, издателями и альтернативными названиями (начиная с 0.2.3).
- Постраничное чтение: свайпы и кнопки перехода вперёд и назад.
- Прямые HTTPS-запросы к MangaLib и серверам изображений: отдельный сервер
  и Python на устройстве не нужны.
- Скользящий буфер: текущая страница и четыре следующие загружаются
  последовательно асинхронно. При открытии ещё не загруженной страницы
  фоновый запрос отменяется, чтобы не задерживать чтение.
- Две предыдущие загруженные страницы остаются в памяти для возврата
  без повторного скачивания. Всего в памяти не более семи страниц;
  при нехватке памяти остаётся только текущая.
- Адреса серверов изображений запрашиваются заранее и сохраняются между
  запусками; последний успешно использованный сервер получает приоритет.
- Зум и перемещение увеличенной страницы.
- Необязательный офлайн-снимок API для проверки интерфейса.

Закладки, сохранение целых глав, вход в аккаунт и выбор перевода пока не реализованы.
Приложение не обходит закрытые главы, ошибки сертификатов и ограничения HTTP 403/429.
Это неофициальный экспериментальный клиент, не приложение администрации MangaLib.

## Управление

Введи название и нажми «Поиск», выбери мангу, затем «Открыть главы» и главу.
Карточка прокручивается; отсутствующие поля показываются как «Не указано».
Обложка загружается отдельно от информации и не задерживает загрузку глав.
«Назад» возвращает из чтения к главам, затем к карточке и результатам поиска.
Кнопка режима переключает
**Прямой API** и **Снимок API**. Кнопка «Назад» возвращает к списку.

- Двойное нажатие на изображение увеличивает до **2,5×** вокруг выбранной точки;
  повторное возвращает **1×**.
- При масштабе **1×** свайп влево открывает следующую страницу, вправо — предыдущую.
  При увеличении свайпы перемещают изображение, не перелистывая страницу.
- Увеличенную страницу можно перемещать пальцем, в эмуляторе — перетаскиванием мышью.
- Стандартный `UIScrollView` поддерживает масштабирование двумя пальцами до **4×**.
- При перелистывании и выходе из главы масштаб и положение сбрасываются.

Двойное нажатие, перетаскивание, возврат к 1× и свайпы в обе стороны
проверены в LightTouch. При увеличении свайп не меняет страницу;
на первой странице свайп вправо не выходит за границы главы.
Синтетический pinch двумя контактами в тестовом прогоне не увеличил страницу;
работа этого жеста на физическом устройстве пока не подтверждена.

## Иконка в стиле iOS 6

Используется исходная иконка MangaLib из предоставленной ссылки RuStore.
Стандартный глянцевый блик, скругление и тень добавляет сама iOS 5/6,
поскольку `UIPrerenderedIcon` выключен. Логотип и цвета не перерисованы.
На современных версиях iOS старый системный блик может отсутствовать.

Готовые иконки уже включены в репозиторий; Python для сборки не нужен.

Версия для домашнего экрана iPad 1 — `Resources/Icon-72.png` (72×72).
Исходник и ссылка на него: `tools/artwork/`.

## Буфер

Подкачка начинается сразу при открытии главы и продолжается после каждой загрузки
и перелистывания. `Буфер: 5/5` означает, что все пять страниц окна уже в RAM.
Окно сдвигается вперёд, в конце главы уменьшается. Заполнение зависит от скорости
сети: временные `4/5` нормальны, пока следующая страница загружается.

В памяти хранятся до семи объектов `UIImage`: текущая страница, четыре следующие
и две предыдущие загруженные. `Назад: 2` означает, что доступны две страницы
истории без повторного запроса. Более старые страницы вытесняются.
При предупреждении о нехватке памяти остаётся текущая страница; перелистывание
возобновляет подкачку. Выход из чтения очищает буфер; устаревшие ответы игнорируются.

Временные сетевые ошибки получают ограниченные повторы. Если серверы недоступны,
страница повторяется в фоне с паузами 5 и 10 секунд, не блокируя другие страницы.
После исчерпания попыток можно вернуться на проблемную страницу для новой загрузки.
HTTP 403/429 и ошибки сертификатов не маскируются автоматическими повторами.

## Сборка

Нужны Rust, [meow и его iOS toolchain](https://github.com/sqmrak/meow).
На Windows сборка проверена через WSL Debian. SDK 6.1 используется для сборки,
минимальная версия приложения остаётся iOS 5.1.

```sh
git clone https://github.com/tayga16/MangaLib6.git
cd MangaLib6
meow setup toolchain
meow setup sdks --sdk 6.1
meow build MangaLib6-ipa
```

Результат текущих исходников: `build/MangaLib6_0.2.3.ipa`.
Если `meow` не в `PATH`, укажи путь
к собранному бинарнику, например `~/meow/target/release/meow`.

Публичный IPA собирается без офлайн-снимка и работает через прямой API.
Офлайн-режим без снимка пуст.

## LightTouch

Проверено в LightTouch 0.0.13, iPad/iOS 5.1.1 с **Direct internet**
и **Local network access**. Установи IPA в свою библиотеку устройств.

Перед установкой штатно выключи гостевой iPad. После установки запусти его
в интерфейсе эмулятора, разблокируй экран и открой MangaLib6.
Не устанавливай IPA поверх работающего гостя и не выключай его принудительно.

В HyperHLE этой версии сеть не поддерживается, поэтому живой API там не работает.

## Проверено и ограничения

В 0.2.2 таймаут отдельного запроса изображения составляет 8 секунд на сервер,
не на всю загрузку с резервными адресами и фоновыми повторами.
Запросы поиска и данных главы используют таймаут 12 секунд и до двух попыток
при временной сетевой ошибке. Кэша результатов поиска и отмены этих запросов нет.
При временной сетевой ошибке используются другие адреса из API без повторного
долгого ожидания на одном сервере. HTTP 403/429 и ошибки сертификатов
останавливают загрузку, а не обходятся сменой сервера.
Буфер хранит объекты `UIImage`, чтобы повторно не создавать их при перелистывании.
В 0.2.2 буфер дополнительно сохраняет две предыдущие загруженные страницы.
При возврате дальше этого окна, выходе из главы или предупреждении о нехватке
памяти картинку может потребоваться скачать снова. Постоянного дискового кэша нет.
В LightTouch проверен возврат 3 → 2 → 1 без повторного скачивания этих страниц;
максимум буфера в прогоне — семь изображений.
В LightTouch проверены живой поиск, загрузка главы и страниц по HTTPS,
заполнение буфера, переходы из кэша и фоновые повторы после временного
сетевого сбоя, двойной зум, перемещение и сброс двойным нажатием.
Скорость зависит от сети и серверов; при сбоях ожидание может быть долгим.

На физическом iPad запуск, TLS и установка пока не проверены. LightTouch использует
свой сетевой прокси и гостевой сертификат; это функция эмулятора, не сервер приложения.
Его успешная проверка не гарантирует совместимость современного HTTPS с iOS 5.1.
IPA не является App Store-сборкой: для реального устройства потребуется подходящая
подпись или среда установки. Идентификатор `ru.mangapad.apitest` сохранён
для обновления ранних тестовых версий.

Обработка memory warning и отбрасывание устаревших ответов реализованы, но
отдельными принудительными тестами не проверены. API MangaLib может измениться.

## Структура

- `src/main.m` — нативный UI, API, буфер и зум (Objective-C, MRC).
- `Info.plist`, `meow.toml` — метаданные приложения и сборка.
- `Resources/` — готовые иконки приложения.
- `tools/artwork/` — исходная иконка и ссылка на источник.

Сборочный toolchain: [meow by sqmrak](https://github.com/sqmrak/meow).
